# VeriStep public evidence

This repository contains small, public demonstration artifacts for VeriStep.
Each VeriStep deal freezes the exact Git commit, blob, path, content type, byte
length, and SHA-256 digest before GenLayer validators review the complete bytes.

The files here are test briefs, not confidential documents and not settlement
decisions. The VeriStep Intelligent Contract remains the sole authority for
obligation assessment, deadlines, entitlements, and native transfer dispatch.
Studio Next cannot verify a native transfer receipt inside the contract, so a
dispatched transfer is never described here as confirmed payment.

`templates/` contains user-selectable sources. `fixtures/` contains the three
commit-pinned hackathon demonstrations: no fault, A introduces an error, and B
introduces an error.
