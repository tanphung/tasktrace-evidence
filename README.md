# TaskTrace public evidence

This repository contains small, public demonstration artifacts for TaskTrace.
Each TaskTrace deal freezes the exact Git commit, blob, path, content type, byte
length, and SHA-256 digest before GenLayer validators review the complete bytes.

The files here are test briefs, not confidential documents and not settlement
decisions. The TaskTrace Intelligent Contract remains the sole authority for
obligation assessment, deadlines, payout, refund, and receipt confirmation.
Immutable public demo artifacts for TaskTrace GenLayer validator verification
